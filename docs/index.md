# Git y GitHub

## Guía práctica de control de versiones

Bienvenido a un manual de consulta y aprendizaje de **Git** y **GitHub** para estudiantes de desarrollo de software.

Aprenderás a gestionar versiones de tus proyectos, documentar cambios, trabajar con repositorios remotos y colaborar con otros desarrolladores. Los ejemplos se realizarán principalmente desde la terminal y Visual Studio Code, con referencias a Windows y Linux.

!!! info "Cómo utilizar la guía"
    Sigue los capítulos en orden cuando estudies Git por primera vez. Más adelante podrás acudir directamente a los capítulos de consulta, problemas frecuentes y comandos.

## Recorrido de aprendizaje

1. Comprender Git, instalarlo y crear un primer repositorio.
2. Registrar y consultar cambios con seguridad.
3. Publicar proyectos y sincronizarlos con GitHub.
4. Trabajar con ramas, resolver conflictos y colaborar.
5. Aplicar buenas prácticas en proyectos Java y Maven.
6. Completar un proyecto integrador de control de versiones.
