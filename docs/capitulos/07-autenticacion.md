# 7. Autenticación y seguridad

## Objetivos de aprendizaje

Al finalizar este capítulo, el alumnado deberá comprender y aplicar los conceptos y procedimientos indicados a continuación.

## Contenidos previstos

Autenticación HTTPS; gestores de credenciales; tokens personales; SSH; claves públicas y privadas; no publicar secretos; permisos y revocación.

## Práctica inicial

Identifica qué archivos o datos de autenticación nunca deben subirse a un repositorio.
