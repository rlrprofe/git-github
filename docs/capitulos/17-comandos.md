# 17. Guía rápida de comandos

!!! note "Capítulo en desarrollo"
    Este archivo contiene el esquema didáctico inicial. Se ampliará con explicaciones detalladas, ejemplos de terminal, capturas, actividades y soluciones.

## Objetivos de aprendizaje

Al finalizar este capítulo, el alumnado deberá comprender y aplicar los conceptos y procedimientos indicados a continuación.

## Contenidos previstos

Referencia de comandos por objetivo: iniciar, registrar, consultar, sincronizar, ramificar, fusionar, recuperar y diagnosticar.

## Práctica inicial

Elabora una chuleta personal con los diez comandos que más utilices.

## Comprobación del aprendizaje

- Explica qué has hecho y por qué.
- Conserva las evidencias relevantes de los comandos utilizados.
- Anota cualquier error encontrado y cómo lo has resuelto.

## Tabla de consulta rápida

| Objetivo | Comando |
|---|---|
| Comprobar estado | `git status` |
| Preparar un archivo | `git add archivo` |
| Registrar cambios | `git commit -m "Mensaje"` |
| Ver historial breve | `git log --oneline` |
| Ver diferencias | `git diff` |
| Ver ramas | `git branch` |
| Cambiar de rama | `git switch nombre-rama` |
| Descargar información remota | `git fetch` |
| Publicar commits | `git push` |
| Integrar cambios remotos | `git pull` |

!!! warning "Importante"
    No ejecutes comandos destructivos como `git reset --hard` sin comprender qué cambios se perderán.
